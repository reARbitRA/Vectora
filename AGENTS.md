# Agent Instructions & Project Conventions

## Living Project Documentation Rule
- **File Tree Synchronization**: Whenever any new file or directory is created, moved, renamed, or deleted anywhere in the workspace, you **MUST** update `/docs/FILE_TREE.md` to reflect the changes in both the ASCII directory tree and the module breakdown table.
- **Architectural Scope**: Respect user intent and avoid introducing unsolicited features or secondary layers outside the explicit scope requested by the user.
